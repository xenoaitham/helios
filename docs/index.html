a legacy enterprise, in a compose file

HELIOS modernizes four "legacy" sources - a SOAP OrderManagement service, nightly CSV drops, a flaky REST API and a busy OLTP database - into a governed dimensional warehouse: Debezium CDC, Airflow orchestration, dbt transformations, Great Expectations quality gates with dead-letter quarantine, Marquez lineage, Prometheus/Grafana. Personal project, COMPLETE: every number below is reproducible with a make target.

SOAP 1.1 / spynePostgres x3 FastAPIKafka + DebeziumAirflow 2.10 dbtGreat ExpectationsMarquez Prometheus + Grafanarootless docker

run it yourself

git clone https://github.com/xenoaitham/helios.git
cd helios
make up          # 17 containers, wait-gated on health (first run seeds the sources;
                 #  fresh volume: non-zero on cdc-sink by design until the one-time CDC bootstrap)
make cdc-setup && docker compose restart cdc-sink   # that one-time bootstrap, then `make up` again
make smoke-test  # green end-to-end: 26 infra checks + a real orchestrated close
make run-etl     # trigger the full pipeline and watch it
make docs-verify # the docs honesty sweep: targets, paths, evidence, no unverifiable numbers
